# راه‌اندازی نسخه قابل‌حمل Persian Site Assistant

این بسته برای اجرای پروژه روی رایانه دیگری با Docker ساخته می‌شود. تصویر API شامل برنامه FastAPI، مدل embedding فارسی E5، اسناد دانش و فایل‌های ایندکس برداری است. تصویر وب نیز سایت، ویجت و Nginx را شامل می‌شود.

**پیش‌نیازها**
- Docker Desktop با Linux containers در ویندوز یا Docker Engine و Docker Compose در لینوکس.
- اتصال اینترنت برای فراخوانی ارائه‌دهنده LLM.
- یک کلید API از ارائه‌دهنده سازگار با OpenAI.
- فضای دیسک کافی برای دو image و مدل embedding (تصویر API بزرگ است).
- این بسته برای معماری CPU سیستم سازنده (معمولاً `linux/amd64`) ساخته می‌شود. برای اجرای بومی روی ARM باید imageها روی سیستم ARM دوباره build شوند.

فایل فشرده می‌تواند بدون نیاز به دانلود مجدد مدل و وابستگی‌ها به سیستم مقصد منتقل شود. ساخت اولیه imageها روی سیستم سازنده به اینترنت نیاز دارد؛ اجرای دستیار برای ارتباط با API مدل زبانی نیز به اینترنت نیاز دارد.

Ollama روی رایانه مقصد لازم نیست. کلید API فقط در فایل محلی `.env` قرار می‌گیرد و داخل image ساخته‌شده یا آرشیو image قرار داده نمی‌شود.

## اجرای بسته آماده

1. فایل `persian-site-assistant-portable.tar.gz` را استخراج کنید. در ویندوز می‌توانید از دستور `tar -xzf persian-site-assistant-portable.tar.gz` یا ابزار 7-Zip استفاده کنید.
2. از فایل نمونه تنظیمات، فایل محلی بسازید:

PowerShell:
```powershell
Copy-Item .env.example .env
```

Linux/macOS:
```bash
cp .env.example .env
```

3. مقادیر زیر را در `.env` وارد کنید. مثال Groq است؛ مقدار مدل باید با مدل فعال حساب شما مطابقت داشته باشد:

```ini
LLM_API_KEY=کلید-واقعی-شما
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_MODEL=نام-مدل-فعال-در-حساب
LLM_TIMEOUT_SECONDS=120
```

4. imageها را بارگذاری کنید:

```bash
docker load -i images.tar
```

5. سرویس‌ها را اجرا کنید:

در ویندوز می‌توانید به‌جای اجرای دستی مراحل بارگذاری و اجرا، `START-HERE.ps1` را باز کنید. این اسکریپت در صورت نبودن `.env` ابتدا فایل نمونه را ایجاد می‌کند و از شما می‌خواهد کلید و مدل را وارد کنید؛ سپس با اجرای دوباره، imageها را بارگذاری و سرویس‌ها را روشن می‌کند.


```bash
docker compose up -d
```

6. سایت را باز کنید:

- وب‌سایت: http://localhost:8080
- مستندات API: http://localhost:8080/docs
- سلامت API: http://localhost:8080/health
- آماده‌بودن دستیار: http://localhost:8080/ready

گزارش‌ها:
```bash
docker compose logs -f api
```

توقف:
```bash
docker compose down
```

## نکات مهم
- مدل E5 و ایندکس در image API قرار دارند؛ در رایانه مقصد دانلود مدل یا اجرای اسکریپت ساخت ایندکس لازم نیست.
- برای تغییر اسناد دانش یا مدل embedding باید image جدید ساخته و بسته قابل‌حمل دوباره تولید شود.
- فایل `.env` را به افراد دیگر ارسال نکنید؛ هر استقرار باید کلید API مخصوص خودش را داشته باشد.
- سایت از همان origin به مسیر `/api` درخواست می‌فرستد و Nginx آن را به FastAPI هدایت می‌کند؛ نیازی به تنظیم CORS روی مرورگر نیست.
- برنامه برای پاسخ‌گویی به مدل زبانی به اینترنت نیاز دارد.
- این نسخه فاقد احراز هویت و محدودکننده نرخ توزیع‌شده است. آن را بدون کنترل دسترسی در اینترنت عمومی قرار ندهید.
- شرکت، محصولات و قیمت‌های داخل سایت کاملاً خیالی و صرفاً برای نمایش هستند.

## عیب‌یابی
اگر سرویس API آماده نشد:
```bash
docker compose ps
docker compose logs --tail=200 api
```
اگر کلید یا نام مدل معتبر نباشد، سرویس هنگام راه‌اندازی پیام خطای پیکربندی می‌دهد. اگر ارائه‌دهنده در دسترس نباشد، درخواست چت با خطای کنترل‌شده مواجه می‌شود.
