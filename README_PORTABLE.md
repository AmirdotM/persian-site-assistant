# راهنمای اجرای نسخه قابل‌حمل

این بسته برای اجرای دمو روی یک رایانه ویندوزی دیگر آماده شده است. برنامه، وابستگی‌های Python، مدل E5، اسناد دانش و ایندکس برداری از قبل داخل imageهای Docker قرار گرفته‌اند؛ روی رایانه مقصد نیازی به نصب جداگانه آن‌ها نیست.

## پیش‌نیاز رایانه مقصد

- ویندوز ۱۰ یا ۱۱ نسخه ۶۴ بیتی
- Docker Desktop نصب و در حال اجرا، با حالت Linux containers
- اتصال اینترنت برای ارتباط با سرویس مدل زبانی (LLM)
- فضای خالی کافی برای بارگذاری imageها

روی رایانه مقصد به Python، pip، فایل `.venv`، PyTorch، Sentence Transformers، Ollama یا دانلود مجدد مدل E5 نیازی نیست.

## اجرای دمو

۱. پوشه `portable-demo` را از فلش روی حافظه داخلی رایانه کپی کنید. بهتر است Docker فایل `images.tar` را از روی دیسک داخلی بارگذاری کند.

۲. مطمئن شوید Docker Desktop کاملاً اجرا شده است.

۳. داخل همان پوشه PowerShell را باز کنید و این دستور را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\START-HERE.ps1
```

۴. اسکریپت این موارد را از شما می‌پرسد:

- کلید API سرویس مدل زبانی
- شناسه دقیق مدل در سرویس‌دهنده
- آدرس پایه API؛ برای OpenAI می‌توانید خالی بگذارید
- پورت محلی سایت؛ مقدار پیش‌فرض ۸۰۸۰ است

کلید API با ورودی امن دریافت می‌شود و در فایل یا پوشه فلش ذخیره نمی‌شود. این کلید فقط تا زمانی که کانتینر اجراست در تنظیمات زمان اجرای Docker قرار دارد.

اسکریپت imageها را بارگذاری می‌کند، سرویس‌ها را اجرا می‌کند، آماده‌شدن API و مدل E5 را بررسی می‌کند و سپس سایت را در مرورگر باز می‌کند. پنجره PowerShell را هنگام ارائه باز نگه دارید. برای پایان دمو Enter یا Ctrl+C را بزنید تا کانتینرها متوقف شوند.

آدرس پیش‌فرض سایت:

`http://127.0.0.1:8080`

اگر این پورت اشغال باشد، هنگام اجرا می‌توانید پورت دیگری وارد کنید.

## چه چیزهایی داخل بسته است؟

- برنامه FastAPI و وابستگی‌های Python
- مدل محلی E5 برای embedding پرسش‌ها
- فایل‌های دانش و ایندکس برداری آماده
- وب‌سایت فارسی، ویجت گفت‌وگو و Nginx
- فایل Compose و اسکریپت شروع دمو

در رایانه مقصد نیازی به ساخت مجدد ایندکس یا دانلود مدل نیست. تنها ارتباط اینترنتی زمان اجرا برای ارسال درخواست به سرویس‌دهنده LLM استفاده می‌شود.

## نکات مهم

- این بسته برای اجرای محلی و ارائه حضوری است؛ سایت فقط روی `127.0.0.1` در دسترس خواهد بود.
- imageها برای Linux containers و معماری `linux/amd64` ساخته شده‌اند.
- برای پاسخ‌گویی دستیار، رایانه باید به سرویس‌دهنده LLM دسترسی اینترنتی داشته باشد.
- اگر سرویس‌دهنده LLM در دسترس نباشد یا کلید/نام مدل اشتباه باشد، چت پاسخ نمی‌دهد؛ خود وب‌سایت همچنان باز می‌شود.
- کلید API را در اختیار دیگران قرار ندهید.
- شرکت، محصولات، سناریوها و بازه‌های قیمت داخل سایت کاملاً فرضی و فقط برای نمایش هستند.

## اگر دمو شروع نشد

اسکریپت در صورت شکست، خطای Docker یا گزارش API را در همان پنجره نشان می‌دهد. ابتدا مطمئن شوید Docker Desktop اجرا شده و روی Linux containers است. همچنین وجود هر سه فایل زیر در یک پوشه ضروری است:

```text
START-HERE.ps1
compose.yaml
images.tar
```
